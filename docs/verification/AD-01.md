## Effect and safety audit

AD-01 contract APIs are pure and stdlib-only. They parse caller-provided bytes/objects, validate caller-provided metadata snapshots and trusted registries, and return immutable records or stable failures. They do not read target content, write files, mint identities, dispatch work, call providers, inspect credentials, open sockets, or spawn processes.

`tests/test_ad01_effects.py` imports `autodev.contracts` under a Python audit hook that blocks filesystem effects outside Python source/stdlib reads, subprocess creation, socket use, and destructive filesystem calls. The test also runs parser, migration preview, and unsupported Contract G validation under that guard.

All evidence here is offline/simulated except the local Python test execution itself. No live native provider, MCP, scheduler, account, credential, delivery, or dispatch validation was performed.

## Limitations

- The YAML parser intentionally supports only the documented AD-01 subset, not general YAML.
- Host metadata is injected by callers; AD-01 does not discover symlinks, filesystem case behavior, repo roots, native capabilities, credentials, or schedules.
- Migration is preview-only and reports `applicable=False`, `writes_performed=False`; Contract G repair/validation/recovery plans import as `UNSUPPORTED` with no apply/write/repair path.
- There is no configured third-party linter or typechecker in this stdlib-only repo. The smoke suite compiles source/tests in memory and import/effect guards provide the configured diagnostics surface.
