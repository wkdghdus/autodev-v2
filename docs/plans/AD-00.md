## ADR

Decision: choose standard-library src-layout offline scaffold, metadata-only source imports and synthetic examples.
Drivers: current empty implementation, AD-00 criteria, dependency and live authority constraints.
Alternatives: root-layout package (viable but weaker separation); third-party stack/docs-only (invalid within constraints); targeted legacy reuse (unneeded).
Why chosen: supplies required smokeability with smallest offline surface and explicit import commands.
Consequences: packaging distribution is not verified by module help; audit is bounded local evidence; report bodies and live compatibility remain missing.
Follow-ups: independent verification before roadmap change; body import or live export only when separately supplied/authorized; no opportunistic future milestone.
