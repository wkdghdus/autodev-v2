# AD-00 baseline inventory

This baseline is file-first and offline. It records the evidence available for
AD-00 without probing live Nous, Hermes, GJC, cron, account, provider, billing,
credential, MCP, session, gateway, scheduling, or service state.

## Scope

AutoDev v2 begins with an inert package scaffold, traceable source identity
records, sanitized evidence handling, synthetic example fixtures, and local
effect-audit tests. It does not implement dispatch, onboarding, lifecycle
state, credential discovery, provider routing, cron control, broker management,
or live compatibility checks.

## Known evidence

- `docs/plans/AD-00.md`: approved AD-00 implementation plan.
- `milestones/AD-00.md`: canonical milestone contract.
- `context/SHARED-INVARIANTS.md`: shared safety and verification rules.
- `migration/SOURCES.md`: S1-S3 metadata authority.
- `ROADMAP.yaml`: milestone status authority.
- `evidence/AD-00/source-records.json`: historical source identities, with
  unavailable bodies preserved as unavailable.
- `fixtures/AD-00/*.json`: synthetic state-label examples only.
